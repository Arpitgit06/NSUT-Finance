# KAVACH prototype outcomes

- [ ] Build a working synthetic-data prototype of KAVACH that connects scam detection and repayment distress so analysts can protect customers before collecting.
- [ ] Include twin fraud and repayment-risk scores, portfolio summaries, tiered alert volumes, case-status counts, and animated risk/data-flow indicators on the Overview command center.
- [ ] Include a Tiered Alerts workspace with severity filtering, point-by-point explainable reasons, linked customer and loan context, and investigation entry points.
- [ ] Include a Customers workspace with searchable synthetic profiles, vulnerability and repayment context, victim-to-default bridge indicators, and chronological activity timelines.
- [ ] Include an interactive Mule Network visualization showing synthetic accounts, payees, transactions, suspicious clusters, and selectable graph nodes/edges for relationship inspection.
- [ ] Include a Loans workspace with synthetic loan details, repayment-risk scores, distress signals, payment history, and loan-level timelines.
- [ ] Include an Evaluation Lab with functional fraud and repayment threshold sliders, live confusion-matrix-style outcomes, and precision, recall, and F1-style metric updates.
- [ ] Include a Cases workspace with Open, Contacted, and Resolved counts, case lists and details, status transitions, notes, ownership context, and links back to alerts, customers, and loans.
- [ ] Include functional intervention controls for recall funds, block payee, EMI holiday, customer nudge, and loan restructure, with visible synthetic state changes.
- [ ] Include a Fairness workspace comparing model outcomes and intervention rates across synthetic customer segments, with disparity indicators and threshold-sensitive views.
- [ ] Include a cinematic interaction layer with a 3D hero risk visualization, animated network/data flows, scroll-triggered section reveals, and interactive navigation across Overview, Alerts, Customers, Mule network, Loans, Evaluation, Cases, and Fairness.

- [ ] Extend the prototype beyond the single hero 3D core with scroll-linked 3D scene depth, floating orbital layers, a traversable signal stack, richer motion, and reduced-motion fallbacks while preserving dashboard usability.

- [ ] Match the reference spatial HUD level: fixed process timeline, perspective-safe tethered overlays, synchronized scene phases, scatter/load/plate utility panels, and a clean system-log edge without overlapping elements.

- [ ] Use a true 3D DNA helix for the reference focal object: paired volumetric backbones, evenly spaced base-pair bridges, colored molecular satellites, camera depth, and phase-synced focus.

- [ ] Make Scan, Design, Synth, and Decon camera transitions interactive and scroll-triggered, with synchronized callouts, signal plate, and WebGL focus depth.

- [ ] Fine-tune the helix rotation to a slower molecular pace and use filmic, physically based, shader-driven lighting for a photorealistic emission field.

- [ ] Clicking a DNA base pair emits an interactive particle burst; scrolling down portals the fitted DNA field to the full viewport and scrolling up restores the contained stage composition.

- [ ] Play a short synthesized audio ping on each base-pair click and ease the DNA portal handoff with opacity/transform transitions in both directions.

- [ ] Match the reference video’s continuous scroll camera: wide context, 20% downward push-in/zoom, node highlight with delayed tethered card reveal, 40–60% pull-back with 180° DNA flip/color shift, and final side-profile lock; UI cards and tether lines must move with the DNA focal node.
